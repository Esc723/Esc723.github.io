Spreadsheet Sync for GitLab

Sync issues and merge requests from GitLab into a Google spreadsheet. Connect with a personal access token, or leave it blank to sync public projects only.

What it does

The add-on runs inside Google Sheets. You connect to gitlab.com or to your own GitLab instance (the URL must start with https://), choose a project or a group, and copy issues or merge requests into a new sheet. It does not write your sheet edits back to GitLab.

Your GitLab token, if you provide one, is stored in your own Apps Script user properties. It is not written into the spreadsheet, so other editors of the sheet cannot see it. The add-on talks only to the GitLab host you enter. The developer does not operate a separate application server.

Features

  • Connect to gitlab.com or a self-hosted GitLab instance over HTTPS
  • Optional personal access token with the read_api scope; public projects can be synced with the token left blank
  • Sync issues or merge requests, with filters for state and labels
  • Optional description column, and optional columns for scoped labels such as priority::high
  • Your own columns and formulas stay on the same row as the GitLab item
  • You can rename headers and move columns without breaking the next sync
  • Large fetches resume on the next run and are not written to the visible sheet until they finish
